# MA GROUP — Web Platform

Modern, responsive web platform and administration dashboard for **MA GROUP** (Agricultural Export).

## Technologies
- **Framework:** React 19 + TanStack Start (SSR)
- **Styling:** Tailwind CSS + Radix UI + Lucide Icons
- **Server:** Nitro engine
- **State & Data:** Local-first stores, prepared for PostgreSQL integration on Hostinger VPS

## Development

```bash
npm install
npm run dev
```

The application will start on `http://localhost:3000`.

## Production Build

```bash
npm run build
npm start
```
